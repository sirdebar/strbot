Для запуска:
1. в терминал python -m venv venv
2. в терминал venv/Scripts/activate (для винды) и source venv/bin/activate (для macOS и Linux)
3. в терминал pip install -r requirements.txt
4. в файле .env BOT_TOKEN пишешь токен своего бота из @Botfather ADMIN_ID ставишь из @userinfobot
5. если нужно поменять картинку приветствия то в файле handlers.py на 31 строке меняешь ссылку
6. запуск в терминал python bot.py
